Agar Link & Logo Tidak Hilang Saat Deploy Vercel (Akun / Perangkat Lain)

Pengaturan pada form di atas tersimpan di memori browser (localStorage) perangkat ini. Supaya semua guru/siswa yang membuka link Vercel di perangkat atau akun berbeda langsung terhubung dan logo tampil otomatis, tambahkan Environment Variables di Vercel → Settings → Environment Variables lalu Redeploy:

VITE_WEB_APP_URL
Isi dengan URL Web App (/exec)
VITE_LOGO_FOLDER_ID
Isi dengan ID Folder Google Drive Logo

Kode Google Apps Script (Code.gs)

Salin dan tempelkan kode ini ke menu Extensions → Apps Script di Google Spreadsheet Anda.
